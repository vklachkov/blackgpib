# Disks

This folder has 3 disk images. You can use them to check that everything works. There is one disk with CCOS and two disks with different versions of MS-DOS adapted for these laptops.

These images almost do not have any software. To use them, you need to download software, for example from my archive at gridrepository.org, and prepare your own disk images.

## How to prepare your own disk images

It is easiest to use the graphical tool [GRiDISK](https://github.com/Bs0Dd/GRiDISKCOM) or the console tool from Kirill [@BOOtak](https://github.com/BOOtak) Leyfer [CCOS-disk-utils](https://github.com/BOOtak/CCOS-disk-utils/) to prepare your disk images.

All information about using these tools is described in their README files.
